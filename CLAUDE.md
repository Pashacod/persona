# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## О проекте

Личный сайт-визитка Павла — не портфолио и не блог, а страница о нём как о человеке: кто он, чем занимается,
чем увлекается. Служит заменой резюме/визитки, когда нужно отправить о себе ссылку.

Перед началом работы прочитай [profile.md](profile.md) — это профиль владельца (факты, голос, тон), на котором
основан весь текст в `index.html`. Любые правки контента должны оставаться в согласии с ним.

## Тон и стиль текста

- Сдержанный, по делу. Без пафоса и без приукрашиваний.
- Факты и суть вместо эпитетов и маркетинговых формулировок.
- Ориентир по голосу — сам `profile.md`: короткие честные формулировки, минимум прилагательных.

## Дизайн

- Тёмная, нейтральная палитра (см. CSS-переменные в начале `index.html`).
- Никаких ярких цветов, градиентов, мигающих/всплывающих эффектов и анимаций (кроме уже существующего тихого
  звёздного фона в hero/на странице — он согласован с темой астрономии, новых подобных эффектов не добавлять).
- Простой, спокойный дизайн, без визуального шума.

## Ограничения — чего не делать

- Не превращать в громоздкий проект: это одностраничная визитка, а не веб-приложение.
- Не тащить фреймворки и сборщики (React, Vue, npm-пайплайны и т.п.).
- Чистый HTML/CSS/JS. JS — минимально, только если без него не обойтись.
- Не плодить страницы/секции без необходимости — сайт должен оставаться простым.

## Структура и сборка

Сборки как таковой нет — это статичный HTML-файл, открываемый напрямую в браузере. Скриптов автоматизации в
репозитории нет.

- `index.html` — вся визитка целиком: разметка, CSS и JS в одном файле.
- `profile.md` — первоисточник контента и голоса владельца.
- `images/` — фотографии, на которые ссылается `index.html` (относительными путями `images/...`).
- `Павел - визитка (для отправки).html` — самодостаточная копия `index.html` для рассылки одним файлом:
  изображения из `images/` встроены как base64 data URI прямо в разметку, поэтому файл на порядок больше
  оригинала. Это сгенерированный артефакт, а не источник правды — после любых изменений в `index.html` или
  `images/` его нужно пересобрать заново (вручную инлайнить изображения как data URI), а не редактировать
  напрямую.
